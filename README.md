# Lumina Focus Android prototype v0.3

This repository contains an Android app with a 25-minute focus timer and an embedded YouTube browser using basic host-based tracker/ad filtering.

## Build APK
Open **Actions** > **Build Lumina Focus APK** > select the newest successful run > download **LuminaFocus-debug-apk** under Artifacts. Extract `app-debug.apk` and install or share with Android Quick Share.

## Important limitations
This is a standalone prototype, not a merge of the previous Lumina Focus APK. It does not contain an Android VPN service, complete app blocking, guaranteed YouTube video ad removal, or background music mode. The build and device installation have not yet been verified.
